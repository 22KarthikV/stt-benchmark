# stt-benchmark

A small harness that

1. scores speech-to-text providers on real audio (WER and latency),
2. replays audio over WebSockets to show partial/final transcripts with measured latency, and
3. validates reference transcripts **before** scoring, so bad truth files fail loudly.

Providers: **AssemblyAI**, **Deepgram** (cloud, free credit) and **Vosk** (local, open source).
Dataset: a deterministic 30-clip subset of LibriSpeech `test-clean` (CC BY 4.0).

Notes on reading the table:

- WER is corpus-level: total word edits divided by total reference words over successful clips.
  Failed clips are excluded from WER and counted under Failures.
- Latency is wall-clock, measured by the harness, from the start of the request to the final
  transcript, **including** upload and polling for AssemblyAI. Providers differ in shape (cloud
  round trip vs. local decode), so file latencies are not like-for-like. Vosk's first clip also
  includes loading the model.
- With about 30 clips, p95 is close to the maximum.

## Quick start

```bash
python -m venv .venv
.venv/Scripts/activate          # Linux/macOS: source .venv/bin/activate
pip install -e ".[dev,data,vosk]"

python data/fetch_librispeech.py      # ~346 MB download, MD5-verified, picks 30 clips (seed 1234)
python data/fetch_vosk_model.py       # ~40 MB small English model
cp .env.example .env                  # then add keys; .env is git-ignored

python -m sttbench validate --stream-format
python -m sttbench run --providers vosk,assemblyai,deepgram
python -m sttbench report --update-readme
```

Keys come only from environment variables (or `.env`): `ASSEMBLYAI_API_KEY`, `DEEPGRAM_API_KEY`,
`VOSK_MODEL_PATH`. A provider with no key is reported as `skipped: no key`, never scored as 0.
Model names are configurable (`ASSEMBLYAI_MODEL`, `ASSEMBLYAI_STREAM_MODEL`, `DEEPGRAM_MODEL`)
and recorded in the results. Model names change often; check the providers' docs.

`run` prints how many minutes of audio it sent to each provider so you can watch free-credit use.
Provider free-tier terms (credit amounts, expiry) change and were **not** re-verified from the
official pricing pages; check them when you sign up.

## Streaming demo

```bash
python -m sttbench demo --serve                      # http://127.0.0.1:8000
python -m sttbench demo --provider vosk --file <clip>.wav   # terminal client
```

The server replays a 16 kHz mono clip in 100 ms chunks (3200 bytes) at real time. Per utterance it
logs `time_to_first_partial` and `final_latency` to `results/stream_log.jsonl`. Where a provider
reports audio offsets they locate the utterance in the sent audio; otherwise the harness falls
back to the last chunk sent before the final arrived, which under-reports latency for providers
that lag behind the audio. File replay measures provider plus network latency, not microphone
capture. The `fake` provider is scripted output, labelled FAKE, and is not speech recognition.

## Normalisation (`norm-v1`)

Applied identically to reference and hypothesis: Unicode NFKC and lowercase; digits expanded to
words by a small deterministic rule set (no "and", no year reading); punctuation removed except
intra-word apostrophes; hyphens become spaces; whitespace collapsed. Not done: spelling variants
(colour/color), contractions, filler words, ordinals, currency and percent symbols. These choices
change WER.

## Truth-file validation

`python -m sttbench validate` checks every clip against its transcript and lists all problems
(exit code 2). `run` does this first and aborts before any provider call.

| Code | Meaning |
|---|---|
| `MISSING_TRUTH` / `MISSING_CLIP` | clip without transcript / transcript without clip (error with `--strict`) |
| `EMPTY_TRANSCRIPT` | empty after normalisation |
| `DURATION_MISMATCH` | words per second outside 0.5-6.0 for the clip length |
| `MISALIGNED` | mostly non-letters, one repeated token, or wrong script |
| `BAD_AUDIO` | unreadable WAV, or not 16 kHz mono 16-bit with `--stream-format` |

Limits: these are offline heuristics. They catch gross errors (the wrong clip's text, truncation,
junk), not a single wrong word, and **not a mislabel of the same length**. The optional
`--sanity-provider` ASR cross-check described in the spec is not implemented.
